# Additional Ideas

Beyond the initial six calculators, these come up often enough in a workshop to
be worth adding. Roughly ordered by usefulness/effort.

## Already folded into the six calculators

These were originally listed here but now live inside an existing calculator:

- **Chain wear / replacement** → [drivetrain.md](calculators/drivetrain.md).
- **Wheel circumference / speedometer calibration** →
  [tire.md](calculators/tire.md).
- **Spoke tension converter** →
  [wheel-building.md](calculators/wheel-building.md).
- **Crank length suggestion** → [frame-size.md](calculators/frame-size.md).

## High value, low effort

- **Torque calculator + spec reference.** Convert Nm ↔ in·lbf ↔ ft·lbf, plus a
  reference table of common fastener torque specs (stem, seatpost clamp, disc
  rotor bolts, cassette lockring, pedals, etc.). Prevents stripped/undertightened
  bolts — very common in community workshops.
- **Unit converter.** mm ↔ inch (incl. fractional), bar ↔ psi, kg ↔ lb,
  km/h ↔ mph, Nm ↔ in·lbf. A shared utility that also underpins the other tools.

## Medium

- **Gear range / cadence overlap visualiser.** Extends the drivetrain calc: plot
  speed-vs-cadence bands per gear to spot gaps and redundant gears; compare two
  drivetrain setups side by side.
- **Bottom bracket / thread standard identifier.** Reference for BSA/ITA/BB30/
  PF30/T47/etc. by shell width and diameter — helps identify what a frame takes.
- **Rotor & brake compatibility.** Rotor size vs adapter needed (IS/post/flat
  mount), mineral oil vs DOT, pad shapes.
- **Crank length suggestion.** Rough guidance from inseam/height; pairs with the
  frame-size and drivetrain (gain-ratio) calculators.
- **Saddle height / setback & KOPS fit.** Extends frame sizing with fore-aft and
  a starting position.
- **Headset / bearing size reference.** Standards (e.g. IS/ZS/EC), common
  cartridge bearing numbers by dimension.
- **Tire/rim width compatibility.** Recommended tire-width range for a given
  internal rim width (ETRTO/ISO guidance), and vice-versa.

## Nice to have

- **E-bike range estimator.** From battery Wh, assist level, rider power, terrain
  — reuses the power model.
- **Ideal tire pressure logbook.** Save the shop's or a rider's preferred numbers.
- **Component weight comparison / build weight tally.**
- **Ratio finder for fixed/singlespeed** including magic-gear chain-tension check
  for horizontal dropouts.

## Cross-cutting nice-to-haves

- **Printable / shareable results** (e.g. a spoke-length ticket to tape to a
  wheel build, or a chain-length note).
- **Presets for the shop's common bikes/wheels** so volunteers don't re-enter the
  same numbers.
- **Multilingual labels** if the community workshop serves a mixed-language crowd.
- **A short "how this is calculated / source" panel** on every calculator, which
  the specs already provide the content for. Keeps the tool trustworthy.
